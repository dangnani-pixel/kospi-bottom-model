# 코스피 바닥 신호판

`kospi_bottom_model.py`가 만든 `signals_daily.csv`와 `report.md`를 열어 지수, 판정 구간, 체크 항목 충족 여부를 그래프로 보는 정적 페이지입니다.

- GitHub Pages에서 열면 가상 예시 데이터가 먼저 나옵니다. **결과 파일 열기**로 두 파일을 고르면 바뀝니다. 파일은 브라우저 안에서만 읽습니다.
- 로컬에서는 `index.html`을 결과 파일과 같은 폴더에 두고 `python -m http.server 8000` 후 `localhost:8000`을 열면 자동으로 불러옵니다.

참고용 시각화이며 매수·매도 판단이나 투자 자문이 아닙니다.
